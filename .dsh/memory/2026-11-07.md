# 2026-11-07 低端机长期运行稳定性专项修复

## 背景
用户要求以「低性能移动设备长期挂机稳定性」为重点做代码审查并落地修改。

## 改动（全部已实施）
### effects.js
- 自适应降级补上「出帧间隔」通道：`tick()` 传 `drawGap`，`sampleQuality(gap, drawMs, drawGap, targetGap)`。
  - `gapEma` 仍看 rAF 刷新节奏；`drawGapEma` 按目标帧间隔倍数判掉帧（避免 30fps 档自身 33ms 被误判）；`drawEma` 保留。
  - `stats()` 新增 `drawGapMs`。
- iOS / Firefox 无 `navigator.deviceMemory` 时的低内存兜底：移动端 + `hardwareConcurrency<=4` 视为 LOW_MEM（烘焙 1.5x、变体 16/16/24）；`readLevel()` 同步兜底为 light。
- 注意：`window.ElainaFX` 接口签名不变。

### script.js
- 课程项改用 DOM API + `textContent` 构建（原 innerHTML 拼接 = 存储型 XSS）；长按改容器事件委托 + `dataset`，长按后吞掉一次 click，避免误开导入框。
- 新增 `safeParse()`：课表/定位/天气缓存解析失败不再打断 `init()`；坏定位配置自动清除。
- 新增 `fetchWithTimeout()`：天气/逆地理/城市搜索 10~12s 超时，弱网不再无限挂起。
- 新增 Wake Lock：首次用户手势后申请屏幕常亮，`visibilitychange` 恢复可见时重申请，失败静默。
- 背景：`scheduleBackgroundSwitch()` 按当前特效档位调整轮换间隔（light/off 翻倍）；`loadBackground()` 加 15s 超时、失败只降级重试一次；淡出 1.7s 后清掉旧图层背景图释放内存。
- 雷电：`thunderTimer`（下一次闪烁）与 `thunderClearTimer`（移除 class）分离；天气转晴时取消待播闪屏。
- `updateTime()`：所有 DOM 写入前判等；农历/节日按天缓存；课表刷新改用「年月日时分」key（比 `getSeconds()===0` 抗漂移）。
- `handleMotion` 限流 10Hz；`updateCourseDisplay` 未导入时标签显示「课表」；`.ics` 解析要求 DTSTART+DTEND，EXDATE 支持仅日期写法（按同一天匹配）。
- 文件选择后清空 input.value，允许重复选择同一文件。

### bemfa.js
- `reconnectPeriod: 0`，改指数退避 5s→10s→…→300s 封顶。
- 页面 `hidden` 时主动断开，恢复可见再连；`desired` 标记区分「用户想连」与「临时断开」。
- mqtt 改为按需动态加载（10s 超时），不再在 index.html 里同步阻塞首屏；未加载/加载失败只给状态提示，不抛 `ReferenceError`。
- 旧连接 close 回调判等 `client !== c`，不再误报「正在重连」；连接序号防止异步加载期间的旧回调抢连。

### index.html / 启动
- Google Fonts 改 `media="print"` + onload 切 `all`，不阻塞首屏；农历库改 `async`。
- `script.js` 初始化从 `window.load` 改为 `DOMContentLoaded`（defer 下立即执行），不再等外部资源。

### style.css
- 删除死变量 `--bg-url`。
- `body.fx-off` / `body.fx-low` 时停掉 `.progress-fill::after` 与 `.top-left::before` 的无限动画。

### 工程
- 新增 `.gitignore`，忽略本地记忆目录（当时叫 `.workbuddy/`，2026-11-17 已迁到 `.dsh/`）与系统杂项。

## 验证
- `node --check` 三个 JS 文件通过。
- Chrome DevTools MCP 加载 `index.html`：时间/农历/天气/特效正常，控制台无 error/warn。
- 损坏 localStorage（`elaina_courses`、`elaina_location`）后刷新：不白屏，标签显示「自由」，坏定位被清除，天气照常。
- 恶意 `.ics` 标题 `<img src=x onerror=...>`：`hasImg:false`，仅作为文本显示，`window.__xss` 未置位。
- 长按课表项：`skipped=true`，随后的 click 被吞掉；第二次 click 正常触发导入。
- 特效页回归 sakura/star/rain/snow/fog：`errs:[]`，`drawMs` 0.07~0.64ms，空闲 `downgrade=0`。
- CPU 20x 节流：`downgrade` 升到 1（drawMs>8ms 生效）；恢复 1x 后回 0。
- 连续 8 次背景切换：旧图层 `background-image` 被清成 `none`，heap 无增长。
- `.ics` 解析：RRULE+COUNT+EXDATE（带时间/仅日期）与缺 DTEND 丢弃均符合预期。
