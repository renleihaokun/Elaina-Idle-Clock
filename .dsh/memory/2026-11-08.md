# 2026-11-08 32 位 Android / MIUI 12.5 长跑稳定性专项（第二轮）

## 背景
用户反馈：32 位 Android 10 + MIUI 12.5 + 32 位 Chrome，长时间挂机偶发
- 毛玻璃模糊丢失
- 网页卡死但浏览器/系统还活着，点击或刷新恢复
- 网页黑屏，需要手动刷新
- 以及其它长跑问题

本轮按「先查根因、再修」处理，未改视觉身份。

## 已确认的根因（有实测证据）
1. **壁纸 API 返回原图，且重复解码**
   - 实测 12 次 `https://elaina.haokun.me/?t=...`：3 次 3840×2160（解码 31.6MB）、1 次 2880×2136（23.5MB）、8 次 1920×1080（7.9MB）。
   - 旧代码 `new Image()`（CORS）解码一次，再给 CSS background 同一个 URL，浏览器又走一次请求/解码；网络记录里同一 URL 出现两次。
   - 旧代码设置 CSS 背景后立刻开始 1.5s 淡出旧层；新层 CSS 资源尚未解码时旧层已透明 → `#111` 黑屏。
   - 图库仓库已有 `/imgs/thumb/manifest.json`（57 张 640px 缩略图，单张解码 0.88MB，CORS `*`），旧时钟完全没用。
2. **rAF 多链 bug**
   - 旧 `tick()` 内调 `sampleQuality()` → `applyQuality()` → `requestAnimationFrame(tick)`，`tick` 末尾又排一次；每次画质切换多一条链。
   - 实测 7 次画质切换后 pending = 8；链数线性增长，长跑越卡，刷新才清空。
3. **自适应判据假设 60Hz**
   - 旧 `gapEma > 34` 判卡、`gapEma < 24` 才升级；Chrome 省电模式/MIUI 限帧到 30fps 时 33ms 是正常值，一旦降级永远升不回去；`fx-low` 还会直接关 `backdrop-filter` → 毛玻璃永久消失。
   - 旧 `.widget` 有 `transform: scale()` + `transition: transform`，Chromium issue 40175472：transform 过渡期间会丢 backdrop-filter。
4. **黑屏/卡死的放大器**
   - 4K 解码 + 两张全屏 `<div>` 背景 + 全屏 canvas + 4 个 backdrop-filter 表面；32 位进程地址空间和 MIUI 内存管理下容易触发 GPU 纹理回收/页面卡顿。
   - 无可见性/watchdog/背景审计；rAF 内任何异常会让循环永久死掉。
   - 巴法云把亮度调到 0 时，内容其实还在全速渲染，夜里白白耗电/发热；且 MQTT 断线后只能刷新恢复。

## 改动清单（全部已落地）
### 壁纸
- `index.html` 背景从 `<div class="bg-layer">` 改为 `<img class="bg-layer" draggable="false">`。
- `script.js` 新增 `THUMB_MANIFEST`/`THUMB_BASE`/缓存（24h）；优先 640 缩略图，非低端才回退原图。
- 双 `<img>` 预加载：`preloadNextBackground()` 先加载到非当前层，`await img.decode()` + `naturalWidth>0` 后才 `applyPendingBackground()`；新层先亮、旧层再淡出。
- 旧层 1.9s 后释放；失败保留旧图；两层都空时用 body 深紫渐变兜底。
- 增加 15s 背景审计：当前层必须有 `src` + `naturalWidth>0` + 可见；连续 3 次异常才做受保护刷新（10min 内最多一次）。
- 4K 原图只在非低端设备、缩略图 manifest 全挂时兜底。

### rAF / 画质
- `effects.js` 改为单调度器：`scheduleFrame()` 保证最多 1 个 pending；`rafGen` 代际作废旧回调；`restartLoop()` 统一重启。
- `tick()` 用 try/catch/finally，异常不再让循环死掉；连续错误 >10 次才停。
- 2s watchdog + visibility/pageshow/focus/pointerdown 恢复；`stats()` 暴露 `rafLive/rafGen/tickAge/transitions/paused`。
- 画质改为相对基线：`baselineGap` 学习当前 rAF 节奏；`jank > max(34, base*1.6)`，`roomy < base*1.25`；持续 3s 才降、30s 富余才升、20s 冷却。
- `DRAW_ROOMY_SLACK` 从 1.3 放宽到 1.55，修「30Hz 屏 + 20fps 档按 2 帧出帧 66ms，永远差 1ms 升不回去」。
- `fitCanvas()` 加像素预算（低端 1.6M / 普通 3.2M），尺寸不变不重写 `cv.width/height`。
- 粒子/一次性对象回池；`fx-low` 只降粒子/帧率/装饰，不再关毛玻璃。
- `stop()`/`setLevel('off')` 清空 canvas，避免关闭特效后画面冻住。

### 毛玻璃
- 启动算 `glassPref`（auto/live/static）和 `glassMode`；Android deviceMemory≤4 或 cores≤4 默认 static。
- 静态玻璃：壁纸 → 64px 小图 → 256px 平滑放大 → 叠 `rgba(14,10,24,.22)` → JPEG dataURL；4 个 widget 按 `transform-origin`+`offsetLeft/Top` 算 `background-size/position`（`P=O*(1-1/S)-offset/S`）。
- 去掉 `.widget` 的 transform 过渡和 `:active` 缩放；弹窗 blur 30px→12px；打开面板暂停 FX。
- 加 `refreshLiveGlass()`（动态模式下重挂 backdrop 表面）。
- 设置面板新增「毛玻璃模式：自动/动态/静态」。

### 夜间黑屏 / 自愈
- `bemfa.js` 亮度持久化 + 派发 `elaina:brightness`；首屏静默应用上次亮度。
- 亮度 ≤8%（opacity≥0.9）：`body.screen-dark`，display:none 内容层，`ElainaFX.setPaused(true)`，暂停背景轮换/天气/闪屏/时间 DOM 写入。
- 黑屏单击本地唤醒 `Bemfa.localWake()`：不发送 MQTT，下一次远程消息仍可覆盖。
- `legacy` 黑屏（mask 丢了但 class 还在）也按 mask 实际透明度兜底。
- 15s 背景审计 + 点击/可见性恢复；长时间隐藏恢复后 `kickCompositor()` 短促 translateZ(0) 踢一下合成器。
- 设置面板新增「每日 04:00 自愈刷新」；**默认关闭**：整页刷新会释放 Wake Lock，可能让常亮屏在刷新后睡下去，需用户自行权衡开启。

### 其它
- `fetchWeather` 单飞 + generation + 隐藏/黑屏跳过；`scheduleBackgroundSwitch` 隐藏/黑屏暂停、恢复按剩余时间补。
- `scheduleThunder` 不再清 `thunderClearTimer`（旧版导致 `thunder` class 永不移除）；隐藏/黑屏不排闪屏。
- `updateTime`/`fetchWitchQuote`/`handleMotion` 在隐藏或黑屏时跳过；`updateCourseDisplay` 加 try/catch。
- `alert()` 改非阻塞 `showToast()`；`updateBattery`/`toggleFullScreen` Promise rejection 加 catch。
- `savedScale` 校验；localStorage 读写加 try/catch；`overscroll-behavior:none`/`touch-action:manipulation`。
- `index.html` 本地资源加 `?v=20261108`；新增 `diag.js`、诊断 overlay、`?diag=1`、设置面板导出诊断。
- `diag.js`：sessionStorage 环形日志（200 条），记录 boot/quality/bg/mask/visibility/error/longtask；`ElainaDiag.snapshot()/dump()/clear()`。
- README 增加老手机说明。

## 验证结果（本机）
- `node --check` script.js / effects.js / bemfa.js / diag.js 全过。
- 本地 HTTP + Chrome DevTools MCP：
  - 默认桌面：`glass=live`，`rafLive=1`，背景 640×360，无 console error。
  - 模拟 Redmi 9A（UA Android + deviceMemory=2 + cores=4）：`glass=static`、`level=light`、`fpsCap=20`、`pixelBudget=1.6M`、`canvasPixels=1.152M`、`glassImg≈4.4KB`、`autoReload=false`、err=0。
  - 静态玻璃截图（1280×720、1600×720、缩放 1.2、竖屏 720×1280）：卡片裁切跟随壁纸，文字可读；见临时截图 `elaina_lowend_1600.webp` / `elaina_static_glass2.webp`。
  - 强制画质切换 + 精确 rAF/ cancel 计数：`pending=1 max=1`；30s 后自动升级回 `downgrade=0`。
  - 30Hz rAF 模拟：`baselineGap≈35ms`，能正常降级并回升到 0。
  - hidden/visible：hidden 后 `running=false,rafLive=0`，visible 后 `running=true,rafLive=1`。
  - 壁纸连切 5 次：每次 640×360，非当前层被清空，heap 3MB；无 4K。
  - 关闭特效：canvas 全透明（alpha=0），无 rAF；恢复 normal 后单链。
  - 人为在 drawImage 抛错：循环存活，诊断记录 `fx-error`。
  - mask 亮度 0：`screen-dark`、main/canvas display none、FX paused；`Bemfa.localWake()` 后恢复、mask 2s 过渡到 0。
  - 静态玻璃切换壁纸：glassImage 哈希变化；1.9s 后下一张预加载。
  - 背景失败（mock loadLayer 全 false + 清空 src）：body 渐变兜底，无异常，`bgEverReady=false` 时不触发刷新风暴。
  - 自动刷新设置：勾选/取消能建立/清除 timer；默认关闭。
  - 像素预算：1920×1080×3 模拟 → canvas 2385×1342 ≈3.2M，不再 5.8M。

## 真机遗留
- 需用户部署后在 32 位 Android 10 / MIUI 12.5 上跑 ≥72h 验收；开 `?diag=1`，出问题用设置里「导出诊断」回传。
- 640 缩略图在 1080p 上略软；如要更清晰，可在 `Elaina-random-img` 用现有 `scripts/generate-thumbs.py` 生成 `imgs/thumb1280/`，时钟优先 1280 回退 640（本轮未改另一个仓库）。
- 自动刷新默认关闭（Wake Lock 取舍）；如真机仍偶发浏览器级卡死，可开启作为兜底。
- 部署：提交后推 GitHub Pages/Cloudflare；`index.html` 已加 `?v=20261108`，旧缓存会自然失效。
