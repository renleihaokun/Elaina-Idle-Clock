## Elaina-Idle-Clock
# 一个挂机时钟，让你的老手机飞起来！  
可导入自定义课表，目前支持`.ics`格式  
建议给老手机用，挂机放那里看着顺眼  

预览网页：<https://clock.elaina.haokun.me>

## 老手机 / 32 位 Android 说明

- 背景优先加载图库的 640px 缩略图，不再每次解码 4K 原图；两张 `<img>` 预加载，解码成功后才交叉淡入。
- 低端机默认使用**静态毛玻璃**（预模糊壁纸），避免实时 `backdrop-filter` 在长时间挂机中掉帧/丢失；设置面板可切成「动态」或固定「静态」。
- 设置面板新增「每日 04:00 自愈刷新」（默认关闭；会短暂重载并释放屏幕常亮，介意勿开）。
- 排查问题时可在网址后加 `?diag=1` 显示诊断条；设置面板里可「导出诊断」查看最近一次运行的画质切换、背景加载、错误与 rAF 状态。
